# Cards Game Bot

Telegram-бот для коллекционирования карточек. Полностью переписан с нуля.

## Возможности

### Пользовательский бот
- Получение карточек (кулдаун 3 часа, без дубликатов)
- Редкости: обычная → легендарная + негативная
- Стрики с ежедневными бонусами
- Кубик (мини-игра на монеты)
- Профиль, коллекция, топы
- Смена никнейма за монеты

### Админ-бот
- Добавление / редактирование / удаление карточек
- Управление пользователями (бан, роли, монеты)
- Статистика и топы
- Рамки на фото по редкости (Pillow)

## Быстрый старт

```bash
# 1. Клонировать / распаковать
cd cards_game

# 2. Виртуальное окружение
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Настройки
cp .env.example .env
# Отредактировать .env — вписать токены и SUPERADMIN_IDS

# 5. Запуск
python main.py
```

## Команды пользователя

| Команда / текст | Описание |
|-----------------|----------|
| /start | Приветствие |
| «мряу» / /meow | Получить карточку |
| /profile | Профиль |
| /top | Топы |
| /dice | Кубик |
| /nick Имя | Сменить ник |
| /help | Справка |

## Команды админа

| Команда | Описание |
|---------|----------|
| /start | Панель |
| /stats | Статистика |
| /ban USERID | Бан |
| /unban USERID | Разбан |
| /setadmin USERID | Назначить админа |
| /setcoins [ID] N | Установить монеты |
| /resetcd [ID] | Сброс кулдауна |
| /delcard ID | Удалить карточку |

## Требования

- Python 3.10+
- aiogram 3.x
- aiosqlite
- Pillow (для рамок карточек)
